# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-07-05
### Added
- Initial public release of GuardrailX.
- FastAPI proxy for OpenAI and vLLM integration.
- PII Redaction using Presidio and Regex.
- Prompt Injection and Jailbreak detection heuristics.
- Content Safety lexicons.
- Policy-as-Code engine with tenant isolation.
- Vite + React frontend dashboard.
- Full OpenTelemetry observability stack.
