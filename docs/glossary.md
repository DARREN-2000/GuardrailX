# Glossary

- **Tenant:** A logical grouping of configuration, users, and logs. Usually represents a single customer or application utilizing GuardrailX.
- **Guardrail:** A specific security check (e.g., PII Redaction, Injection Detection).
- **Policy:** A collection of Guardrails and their configured strictness levels applied to a specific route or tenant.
- **Provider:** An external LLM API (e.g., OpenAI, Anthropic, Ollama).
