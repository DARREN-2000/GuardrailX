# GuardrailX Documentation

Welcome to the official documentation for **GuardrailX**, the deterministic security gateway for non-deterministic AI.

## What is GuardrailX?

GuardrailX provides the enterprise governance and security infrastructure required to deploy Large Language Models (LLMs) safely at scale. It acts as a real-time proxy between your applications and LLM providers, enforcing strict policies, redacting sensitive data, and providing deep observability.

## Key Features

- **Prompt Injection Defense**
- **Jailbreak Detection**
- **Real-Time PII Redaction**
- **Content Safety Filtering**
- **Policy-as-Code**
