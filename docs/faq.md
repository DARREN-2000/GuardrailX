# Frequently Asked Questions

**Q: Does GuardrailX support streaming?**
A: Support for streaming (`Server-Sent Events`) is currently in development. Currently, requests are handled synchronously.

**Q: Can I use my own models for PII detection?**
A: GuardrailX uses `en_core_web_lg` via SpaCy for Presidio. Custom model integration is planned for a future release.

**Q: Is there a cost to use GuardrailX?**
A: GuardrailX is completely free and open-source under the Apache 2.0 license.
