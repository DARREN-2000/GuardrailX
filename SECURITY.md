# Security Policy

## Supported Versions

Currently, the following versions are receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Security is our top priority. If you discover a vulnerability in Aegis, we kindly ask that you report it privately to our security team before disclosing it publicly.

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, send an email to `security@aegis.ai`.

### What to include in your report:
- A description of the vulnerability and its potential impact.
- Detailed steps to reproduce the vulnerability.
- Any relevant logs, screenshots, or Proof of Concept (PoC) code.

### Our commitment:
- We will acknowledge receipt of your report within 48 hours.
- We will investigate the issue and provide regular updates.
- Once a fix is verified, we will issue a CVE and credit you in the release notes.
