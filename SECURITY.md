# Security Policy

## Supported Versions

Currently, the `main` branch and the latest tagged release receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is our top priority. We appreciate your efforts to responsibly disclose your findings, and will make every effort to acknowledge your contributions.

Please **do not** open a public issue for security vulnerabilities. Instead, report them privately:

1.  Navigate to the **Security** tab of this repository.
2.  Click on **Report a vulnerability**.
3.  Fill out the form with as much detail as possible, including steps to reproduce.

Our security team will review the report and respond within 48 hours. If the vulnerability is accepted, we will coordinate a fix and an embargo period before public disclosure.
