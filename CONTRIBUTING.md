# Contributing to Aegis

First off, thank you for considering contributing to Aegis! It's people like you that make Aegis a world-class enterprise AI trust layer.

## Code of Conduct
By participating in this project, you are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Review the [Developer Experience](docs/developer-experience.md) documentation to set up your local environment (Backend, Frontend, DB).

## Making Changes

- Create a feature branch (`git checkout -b feature/my-new-feature`).
- Ensure all new code has tests (Pytest for backend).
- Ensure code passes the linting tools (`pre-commit run --all-files`).

## Submitting a Pull Request

1. Push your branch to your fork.
2. Open a Pull Request against the `main` branch of the upstream repository.
3. Fill out the PR template thoroughly.
4. Ensure all CI checks pass. If tests fail, fix them before requesting a review.
