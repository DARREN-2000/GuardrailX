# GuardrailX Governance

## Overview
GuardrailX is an open-source project designed to provide an enterprise-grade AI governance runtime. This document outlines how decisions are made, how the community operates, and how individuals can become maintainers.

## Roles

### Contributors
Anyone who interacts with the project is a contributor. This includes reporting bugs, suggesting features, improving documentation, or submitting pull requests.

### Maintainers
Maintainers are active contributors who have shown dedication to the project and possess deep understanding of the codebase. They have write access to the repository and are responsible for:
- Reviewing and merging pull requests.
- Triaging issues and guiding architectural decisions.
- Mentoring new contributors.
- Enforcing the Code of Conduct.

## Decision Making
Major technical decisions are made through an RFC (Request for Comments) process, typically utilizing GitHub Discussions or design documents. For smaller changes, discussion on the specific Pull Request or Issue is sufficient. Consensus among maintainers is the goal.

## Becoming a Maintainer
Maintainer status is granted by existing maintainers based on a history of high-quality contributions and active participation in the community.
